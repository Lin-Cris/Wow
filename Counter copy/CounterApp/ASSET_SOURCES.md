# Counter illustration assets

All Counter category illustrations, category icon choices, and the profile mascot in `Assets.xcassets` are original raster assets generated for Counter from the user's supplied and authorized design references. They are bundled as transparent PNGs and rendered as images throughout the app; no screenshots were cropped for production assets.

The asset catalog contains 82 transparent category and avatar PNGs at 384×384: the 15 built-in categories each have their base illustration; 14 have four alternate illustrations, dining has five editor choices, there are five custom-category illustrations, and one purple profile mascot. New imported categories use the Counter receipt illustration by default.

`AppIcon.appiconset/AppIcon.png` is a separate 1024×1024 opaque PNG app icon, created in the Counter visual style from the user's authorized mascot reference and a ledger coin motif. It is configured as the universal iOS app icon. All Counter artwork is independent of BeeCount; no BeeCount source code, illustrations, icons, or bundled resources are included.
